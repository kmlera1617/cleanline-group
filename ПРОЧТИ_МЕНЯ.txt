CleanLine Group — заявки в Telegram без перехода клиента

Chat ID уже установлен: 8293509366.

Для проверки на Mac:
1. Установи Node.js с https://nodejs.org/ (если ещё нет).
2. Открой Терминал, напиши: cd и пробел, перетащи папку сайта в окно Терминала, нажми Enter.
3. Введи: ./start-mac.command
4. Вставь API Token, который выдал BotFather (ввод не виден), нажми Enter.
5. Откроется страница контактов. Заполни форму и нажми «Надіслати заявку».
6. Заказ придёт в личный чат с ботом. Окно Терминала не закрывай, пока тестируешь.

ВАЖНО: токен никому не пересылай и не сохраняй в HTML. Для реальных клиентов после публикации понадобится серверный хостинг Node.js и HTTPS; локальный сервер доступен только на твоём компьютере.
